# The Nestlé Empire

## Run it locally

Needs Node 20.19+ or 22.12+.

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:5173.

To check the production build:

```bash
npm run build && npm run preview
```

## Controls

| Action | How |
| --- | --- |
| Move around | Two-finger scroll (any direction), right-click and drag, or drag empty space |
| Zoom | Pinch, ⌘/Ctrl + scroll, or the + / − buttons |
| Explore a category | Click its hub; its brands rearrange around it |
| See a brand's products | Hover a brand to peek at them, click it to fan them out with names |
| Details | Click any circle or product; the panel shows what it is, who owns it and a link |
| Go back | Esc, click empty space, or use the breadcrumb under the search box |
| Rearrange | Drag any circle; what's attached to it comes along |
| Find something | Type in the search box (press `/` to jump there) |
| Filter by ownership | Click an entry in the Ownership legend to hide it |
| Keyboard | Arrow keys pan · `+` `-` zoom · `0` show everything |
