# The Nestlé Empire

## Run it locally

Needs Node 20.19+ or 22.12+.

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:5173.

To check the production build:

```bash
npm run build && npm run preview
```

## Controls

| Action | How |
| --- | --- |
| Move around | Two-finger scroll (any direction), right-click and drag, or drag empty space |
| Zoom | Pinch, ⌘/Ctrl + scroll, double-click empty space (Shift + double-click zooms out), or the + / − buttons |
| Open a category | Click its circle or its name; it zooms in and the other categories tuck into chips at the screen edges |
| Switch category | Click a chip at the screen edge |
| See a brand's products | Hover a brand to peek at them; click it to fan them out with names |
| Details | Click a category, brand or product; the card shows what it is, who owns it and a link |
| Go back | Esc, click empty space, zoom out past the minimum, the breadcrumb in the top bar, or the browser's back button |
| Rearrange | Drag any circle; what's attached comes along. Drag a bubble far and its line tugs the rest of the map with it. "Tidy up" puts everything back |
| Find something | Type in the search box (press `/` to jump there) |
| Filter by ownership | Click Owned, Part-owned or Formerly Nestlé in the legend (bottom left) to hide or show them. More lists every ownership type and explains the lines |
| Keyboard | Arrow keys pan (Shift for bigger steps) · `+` `-` zoom · `0` show everything · `Esc` up one level |

On a phone: drag with one finger to move, pinch to zoom, and tap to open. Hold a circle, then drag it to rearrange. Categories are in the strip under the top bar, the Key is top left, and you swipe the card down to close it.
